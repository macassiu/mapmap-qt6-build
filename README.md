## 🚀 How to use

1. **Download** the `.AppImage` file
2. **Make it executable**:

   ```bash
   chmod +x MapMap-*.AppImage
3. **Run it:**
  ```bash
  ./MapMap-*.AppImage
  ```

**No installation required — works on all recent Linux distributions (Ubuntu 24.04+, Debian, Fedora, Arch, etc.)**
